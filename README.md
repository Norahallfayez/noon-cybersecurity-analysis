# Noon Cybersecurity Analysis

A cybersecurity analysis of the **Noon e-commerce platform in Saudi Arabia**, completed as part of the **CYS403** course.

This academic project evaluates Noon's cybersecurity posture from a risk-management and governance perspective. It focuses on security threats, authentication, data confidentiality, security policies, Saudi cybersecurity frameworks, and proposed security improvements.

## Project Overview

Large e-commerce platforms process sensitive customer, payment, transactional, and business information. This creates cybersecurity risks involving account compromise, fraud, phishing, data breaches, service disruption, and third-party exposure.

This project analyzes Noon as a large-scale e-commerce information system and evaluates its current security situation, major risks, and possible improvements.

The project covered:

## Identified Security Risks

The analysis considered several major risks affecting e-commerce platforms, including:

- Phishing and social engineering
- Account takeover and unauthorized access
- Data breaches
- Payment fraud
- Third-party seller fraud
- Insider threats
- System downtime and service disruption
- Weak password practices
- OTP-related security limitations

## Authentication & Data Confidentiality

The project evaluated authentication mechanisms such as:

- Username and password authentication
- One-Time Password (OTP) verification
- Session management

It also discussed authentication limitations, including:

- Password reuse
- Phishing
- Reliance on SMS OTP
- Lack of stronger mandatory MFA

Data confidentiality mechanisms included:

- Encryption in transit
- Secure payment processing
- Access control
- Protection of sensitive customer information

## Saudi Cybersecurity & Compliance Context

The analysis considered cybersecurity practices within the Saudi regulatory environment, including:

- National Cybersecurity Authority (NCA) cybersecurity guidance
- Personal Data Protection Law (PDPL)
- Data-protection principles
- Payment-security practices

## Proposed Security Improvements

The project proposed several cybersecurity improvements, including:

- Stronger Multi-Factor Authentication (MFA)
- Biometric or authenticator-based authentication
- Zero Trust Architecture (ZTA)
- Least-privilege access
- Micro-segmentation
- Real-time logging and alerting
- AI-based fraud detection
- Behavioral analytics
- Stronger seller verification
- Improved user-security awareness

## CIA Triad Analysis

The project evaluated Noon using the three core principles of the **CIA Triad**:

### Confidentiality

Protection of customer, payment, and account information from unauthorized disclosure.

### Integrity

Protection of transactions, user accounts, and marketplace data from unauthorized modification.

### Availability

Maintaining reliable access to platform services, especially during high traffic and payment-processing periods.
